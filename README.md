# Healthcare Admissions Analytics (2019–2024)

## 📌 Overview
Analytics system for 55,000+ patient admission records, focusing on **data cleaning, reporting, dashboards, ad-hoc queries, and predictive modeling**.

## 🚀 Key Contributions
- **Data Preprocessing (Python)**  
  Cleaned and structured hospital admission records, engineered new features (admission duration, date parts), ensured reliable input for reporting.  

- **Interactive Dashboards (Power BI, Excel PivotTables)**  
  Visualized admissions, diseases, and billing trends to identify healthcare patterns.  

- **Key Metrics & Reporting**  
  Defined KPIs such as total admissions, average hospitalization days, billing amounts.  
  Developed OLAP-style queries (MDX, SQL-like) to derive ad-hoc insights, e.g.:
  - Top medicines used for cancer treatment  
  - Most common diseases by age group  
  - Admissions by type over months/years  

- **Predictive Analytics (Python)**  
  Built Decision Tree and Random Forest models to forecast patient test results.  
  Random Forest achieved the highest accuracy and revealed key features via importance plots.
